02 · OUR ANSWER

근거 → 해석 → 행동을
하나의 워크스페이스로.

GOPS는 실시간 시장 데이터를 시점이 고정된 evidence snapshot으로 만들고, 질문 의도에 맞는 역할 에이전트가 분석합니다. 결과는 차트 작도·패널 구성·조건 제안으로 연결되지만, 실행 권한은 언제나 사용자와 주문 런타임에 남습니다.

03 · FOR WHOM

초보에게는 맥락을,
숙련자에게는 검증 가능성을.

  • 개인 투자자 — 시장 탐색과 판단 근거를 한 흐름으로
  • 숙련 사용자 — 원천 시점·품질·실패 상태까지 확인
  • 운영자 — 재현 가능한 replay와 감사 가능한 계약

D
Deterministic kernel — 지표·추천 점수·리스크 gate·AI 코치 성과 계산은 코드가 소유하고, LLM은 제한된 의도 해석과 서술을 담당합니다.
S
Safety boundary — provider 실패는 no-data 근거로 낮춰 계속 분석하고, 주문은 Idempotency-Key와 별도 execution runtime으로 중복·권한을 통제합니다.

What makes it trustworthy

✓
Point-in-time first분석·추천·코치 입력은 관측 시점과 cutoff를 보존해 미래 정보 누출을 막습니다.
✓
Evidence before eloquence출처·신선도·품질이 있는 snapshot만 종합하고, 없는 데이터는 추정해 채우지 않습니다.
✓
Idempotent by contractKafka sink와 주문 흐름은 재시도·중복 전달에도 같은 결과를 유지하도록 설계했습니다.
✓
Human-in-the-loopAgent는 분석과 제안만 수행합니다. 주문·계좌 제어는 사용자 확인과 별도 권한 경계를 거칩니다.
✓
No fake market data로컬 런타임도 임의 캔들을 만들지 않고, 데이터 공백과 복구 상태를 그대로 노출합니다.
