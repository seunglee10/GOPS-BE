# Chart Analysis Assets v2 구현 노트

## 문서·코드 조정

- `docs/CHART_AGENT_STRATEGY.md`의 장기 방향에는 오케스트레이터 통합과 레거시 제거가 있으나, 이번 v2 스펙의 명시적 범위에 따라 독립 chart-asset builder를 유지하고 workflow/role/provider 및 레거시 경로를 수정하지 않는다.
- 기존 자산 계약은 단일 v1 schema였다. rollout 호환을 위해 원본을 `chart-analysis-asset-v1.schema.json`으로 보존하고 canonical schema를 v1/v2 union으로 전환한다.
- 기존 worker는 주기마다 별도 query/aggregation을 수행했다. v2는 shared `analysis_candles.py`에서 canonical 1D를 한 번 읽고 1D/1W/1M을 생성하는 경계로 이동한다.
- 기존 serving merge는 timestamp와 호출 순서에 의존했다. v2 primary identity인 candle key와 명시적 source/revision/hash winner를 shared pure function으로 도입하고 기존 route shape는 유지한다.

## 검증·성능 기록

- 묶음 A: Python 3.12.13. `test_analysis_*.py` 8건, market-data 전체 374건(6 skipped), chart-data contract 검사를 통과했다. serving daily live/closed precedence 회귀 1건을 발견해 source class를 명시적으로 분류한 뒤 전체 회귀를 재통과했다.
- 묶음 B: kernel version을 `kernel-v2`로 올리고 interval 설정을 `analytics/config.py` 한 곳에 모았다. pre-seed ATR, tactical/structural pivot과 prominence, bounded zone/touch episode/state, event episode, 3-touch/current-relevance trend, dual-boundary channel, 독립 range를 구현했다. 기존 “range는 항상 존재” 테스트는 v2 정상 무작도 계약과 충돌해 제거하고, 두 점/현재 무관 추세선 억제 테스트로 교체했다. market-data 375건(6 skipped), agent-orchestration 259건을 통과했다.
- 묶음 C: v1 intent compiler는 rollout read 호환 테스트를 위해 보존하고, v2 `curation.py` 경계를 추가했다. compact bundle에는 raw candle과 drawing geometry를 보내지 않으며 LLM은 candidate/fact/condition/relation ID만 선택한다. materializer가 kernel template을 복사하고 `commentary_v2.py`가 검증된 clause와 실제 drawing ID로 rich commentary를 조립한다. Responses 요청은 `store:false`, strict schema, output 1,200 token hard cap을 적용한다.
- 묶음 D: builder를 interval 중심 v1 흐름에서 symbol 중심 v2 흐름으로 전환했다. age gate 뒤 canonical daily bundle을 1회 읽고, interval kernel을 만든 뒤 MTF curator를 최대 1회 호출한다. version/input/higher-summary를 포함한 `preKernelDigest`, build intent, content digest로 kernel·LLM·INSERT no-op을 구분하며 `force`는 fast gate만 우회한다. LLM 장애는 failed가 아닌 `saved_with_warning`/`completed_with_warnings`이고, insufficient input은 기존 asset을 보존한다. v1 agent는 v2 rule-only에 복사하지 않으며 동일 v2 input/candidate가 재검증될 때만 보존한다.
- 묶음 E corpus는 13개 실제 Nasdaq series를 한 번씩 저장하고 172개 as-of episode가 재사용한다. 최종 fresh holdout은 threshold 변경 뒤 새로 고정한 `post-extreme-gate-holdout-v3`이며 `must_draw=52`, `must_not_draw=20`, 최종 drawing 333개, accepted offscreen drawing 23개다. 두 독립 deterministic rubric의 **automated reviewer estimate**는 precision 333/333, 명백히 무의미 0/333, offscreen 현재 관련성 23/23, must-not 불필요 episode 0/20, must-draw recall 52/52였다. 이 수치는 전문가 precision이 아니며 human blind review 전 production rollout은 금지한다.
- level gate를 독립 touch 3회·reaction 2회·현재 2 ATR 이내로, trend를 현재 2.25 ATR·최근 display 15% 이내로, range를 양 경계 합산 6회·현재 1 ATR 이내로 강화했다. stale medium-impact 52주 extreme flag는 hard pass하지 않는다. 최종 rules 평가는 invariant failure 0, drawing median 2/p95 4였다. 전체 episode 계측 p95는 76.49ms로 75ms 목표를 1.49ms 초과했지만, warm-up 5회+single-thread 30회 고정 benchmark는 v2 p95 33.529ms, retained v1 compiler p95 35.715ms, 상대 0.9388배였다. historical pre-v2 feature 구현은 보존돼 있지 않아 상대 baseline은 shared current feature pack 범위다.
- 실제 OpenAI smoke와 12개 stratified pilot을 `gpt-5.2-2025-12-11`에서 재실행했다. pilot은 degraded 0, invariant failure 0, input 593~1,127 tokens/p95 1,108.85, output p95 544.8였다. 동일 bundle 직접 3회 호출의 visual candidate ID는 동일했고 어떤 결과도 저장하지 않았다. Responses `store:false`, 1,200 output hard cap을 유지했으며 key와 raw prompt/response는 출력·저장하지 않았다.
- 로컬 ClickHouse/Redis/Kafka 실스택에서 실제 builder→ClickHouse→FastAPI serving을 관통했다. compact evidence projection 뒤 v2 payload max 10,377 bytes/p95 9,233 bytes(지정 5심볼 재검증 p95 7,264.15 bytes), serving v2 p95 6.28ms와 v1 대비 1.0011배를 기록했다. 첫 저장 뒤 동일 실행은 symbol당 canonical query 1회, kernel/LLM/INSERT 0이었고 Redis key는 job status string뿐이었다. input 변경 후 displayed content가 같으면 INSERT를 생략하고 kernel을 재검증하는 경로도 확인했다.
- 후속 실스택 표본은 사용자 지정 AAPL/AMZN/GOOGL/NVDA/MU만 사용했다. 로컬 Alpaca API는 차단돼 호출하지 않았고, GOOGL/MU 보충은 Nasdaq 공개 일봉을 `/tmp`와 ClickHouse에만 넣었다. 최신 canonical close가 부족한 interval은 기존 v1/v2를 보존하는 `input_insufficient_existing_asset_preserved`가 정상 발생했다. 이는 source freshness 제약이며 가짜 최신 봉으로 통과시키지 않았다.
- v2 전용 Playwright는 desktop/mobile에서 3-layer toggle, focus commentary, flag pixel 존재, 운영 문구와 comma payload를 4건 통과했고 `/tmp` screenshot을 남겼다. desktop은 flag stem pixel을 hover candle date와 대조했다. mobile hover/touch 역매핑은 touch tooltip 범위 밖이므로 이후 엄격 검증 대상에서 제외했다. 일반 chart/layout/build/bundle-size와 전체 보호 회귀도 통과했다.
