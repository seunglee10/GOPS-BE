# Agent Icons

SVG icons served by the GOPS frontend at `/assets/agent-icons/...`.

Rules:

- Keep filenames as `agent-01.svg` through `agent-12.svg`.
- Do not assign role names until agent roles are finalized.
- Map roles to icon files in frontend code or a future manifest when needed.

Example:

```ts
const agentIconUrl = "/assets/agent-icons/agent-01.svg";
```
